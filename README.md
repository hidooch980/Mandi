# پترونبض | سامانه خرید و فروش بنزین و گازوئیل و استعلام قیمت (PWA)

این برنامه بدون نیاز به خرید هاست و دامین روی سیستم خودتان اجرا می‌شود و در **لپ‌تاپ، کامپیوتر، گوشی اندروید و آیفون** قابل باز کردن و نصب است.

## قابلیت‌های کلیدی
- **کشف قیمت گازوئیل از دلال‌ها و کانال واتساپ (`/discovery`)**:
  - ثبت استعلام تلفنی دلال‌ها و پیام‌های کانال/گروه واتساپ (همراه با استخراج خودکار مبلغ از متن پیام واتساپ)
  - محاسبه خودکار سود ثابت هر بشکه (مثلاً خرید ۳۷,۰۰۰,۰۰۰ و فروش ۳۷,۵۰۰,۰۰۰ تومان)
- **خرید و فروش بنزین و گازوئیل (`/orders` و `/inventory`)**:
  - گازوئیل بشکه‌ای ۲۲۰ لیتری (مثلاً خرید ۳۷ میلیون / فروش ۳۷.۵ میلیون -> ۵۰۰ هزار تومان سود)
  - بنزین ۷۰ لیتری (مثلاً خرید ۸ میلیون / فروش ۹ میلیون -> ۱ میلیون تومان سود)
  - بدون ثبت‌نام عمومی مشتری (فقط ورود مدیر و همکار فروش)

## راه‌اندازی ۱۰۰٪ رایگان بدون هاست و دامین

### روش ۱: روی وای‌فای محل کار یا منزل (گوشی و لپ‌تاپ)
روی فایل `start-local.bat` در پوشه پروژه دو بار کلیک کنید. برنامه آدرس شبکه (مثل `http://192.168.1.5:3000`) را نشان می‌دهد که می‌توانید با همان آدرس در مرورگر گوشی اندروید و آیفون باز کنید.

### روش ۲: دسترسی از همه‌جا با اینترنت گوشی (رایگان با Cloudflare Tunnel)
1. برنامه را با `start-local.bat` (یا `npm run start`) اجرا کنید.
2. در یک پنجره خط فرمان دیگر دستور رایگان زیر را بزنید:
```bash
cloudflared tunnel --url http://localhost:3000
```
یک لینک امن `https://....trycloudflare.com` به شما می‌دهد که بدون هزینه هاست و دامین، در آیفون، اندروید و کامپیوتر از همه‌جا باز و نصب می‌شود.
